# Benjamin Buckland portfolio

Static portfolio for GitHub Pages. Serve this repository root; no build step or dependencies are required. The site has no chatbot, backend, API keys, analytics, or automatic external requests.

## Maintenance

Edit `index.html` for content, `style.css` for presentation, and `network.js` for the interactive network. Keep `benjamin-buckland.jpg` beside these files. Check section links, keyboard controls, and narrow-screen layout after edits. Preview locally with `python3 -m http.server 8000 --bind 127.0.0.1`, then open http://127.0.0.1:8000.

Only add content appropriate for a public repository. Never add credentials, private datasets, or the separate chatbot archive. GitHub Pages hosting and any custom domain must be configured separately; this folder does not configure DNS.
